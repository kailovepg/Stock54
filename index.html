📊 เกณฑ์ขั้นต่ำจำนวนเบอร์ (สำหรับเทียบ %จบ ค่าเฉลี่ย)

ใช้ในการ์ดแจ้งเตือน "เซลล์ %จบ ต่ำกว่าเฉลี่ย" — เซลล์ที่ได้รับเบอร์น้อยกว่าค่านี้จะไม่ถูกเอามาคำนวณค่าเฉลี่ย เพื่อกัน % เพี้ยนจากฐานเบอร์น้อยเกินไป

🤖 LINE Bot — ค้นหาข้อมูลรถผ่านไลน์

ให้เซลล์พิมพ์ยี่ห้อ/รุ่น/ทะเบียนในกลุ่มไลน์ บอทจะตอบข้อมูลรถกลับให้อัตโนมัติ (ไม่โชว์ต้นทุน/ค่าใช้จ่ายเด็ดขาด) — เอา Channel Access Token กับ Channel Secret มาจาก LINE Developers Console > Messaging API

💡 หลังบันทึกแล้ว ให้เอา URL ของเว็บแอปนี้ (Deploy URL) ไปตั้งเป็น "Webhook URL" ในหน้า LINE Developers Console แล้วเปิด "Use webhook" ด้วย ไม่ต้องใช้ Group ID ใดๆ เพราะบอทตอบกลับอัตโนมัติตามข้อความที่มีคนทักมา

👁️ คอลัมน์ที่ซ่อนจากพนักงานขาย

ปิด toggle = ซ่อนจาก Sales

🔐 จัดการสิทธิ์การเข้าถึง (เฉพาะ Super Admin)

กำหนดระดับสิทธิ์ของแต่ละบทบาทต่อโดเมนข้อมูล — none = ไม่เห็นเลย, read = ดูได้อย่างเดียว, write = แก้ไขได้, manage = จัดการเต็มรูปแบบ
Super Admin มีสิทธิ์เต็มทุกโดเมนเสมอโดยอัตโนมัติ ไม่ต้องตั้งค่าที่นี่

🔍 เติมสาขาอัตโนมัติจากทะเบียน (_CarCosts)

ใช้เมื่อ copy ข้อมูลต้นทุนจาก Excel มาวางในชีต _CarCosts แล้วไม่ได้ระบุคอลัมน์ "สาขา" ไว้ (เช่น บัญชีต้นทางไม่มีข้อมูลนี้) — ระบบจะค้นทะเบียนที่ไม่มีสาขาทุกแถว เทียบกับทะเบียนที่มีอยู่จริงในชีตสต๊อก/รถออกทุกสาขา แล้วเติมสาขาให้อัตโนมัติเฉพาะกรณีที่เจอสาขาเดียวชัดเจนเท่านั้น (ถ้าทะเบียนซ้ำกันข้ามสาขา หรือหาไม่เจอเลย จะข้ามไว้ให้แก้เอง ไม่เดามั่ว)

📜 ประวัติการแก้ไขข้อมูล (Audit Log) — เฉพาะ Super Admin
